# ComposeLens 0.1.17

- Adds positive and negative boundary tests for implementation versions and evidence ranges.
- Adds a pinned coverage ratchet to normal CI and release validation.
- Adds shared editor tasks and a one-command local format, lint, test, and release-readiness gate.
- Isolates local API checks from a container's potentially read-only Cargo installation cache.
- Preserves the documented 0.1.x API and Rust 1.85.0+ support.
