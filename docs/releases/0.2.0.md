# ComposeLens 0.2.0

- Completes the audited closed-schema Compose key model, including resource metadata, development
  watch execution data, and long-volume options.
- Consolidates resource lifecycle inspection into `external() -> Option<&ResourceExternal>`.
- Retains deprecated Compose `external: { name: ... }` input as
  `ResourceExternal::NameMapping(ExternalNameMapping)` without normalizing it.
- Keeps parsing, project construction, and rendering free of implicit file, environment, provider,
  and runtime access.

## Migration from 0.1.x

- Replace `external_syntax()` with `external()`.
- Match `ResourceExternal::NameMapping` instead of `ResourceExternal::Legacy`.
- Use `ExternalNameMapping` instead of `LegacyExternalName` and `name_mapping()` instead of
  `legacy()`.
