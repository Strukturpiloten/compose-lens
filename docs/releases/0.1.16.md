# ComposeLens 0.1.16

- Adds native service `stdin_open`, `tty`, and `privileged` support across authored, effective,
  generated, and public API boundaries without inferring terminal, security, runtime, or
  cross-format behavior; see the [typed model](../typed-model.md) and
  [generated-document guide](../generated-rendering.md).
- Adds service `logging` across the authored, merged, and generated boundaries; see the
  [typed model](../typed-model.md) and [generated-document guide](../generated-rendering.md).
- Adds generated service-network attachments with optional raw IPv4 and IPv6 identities.
- Retains authored and merged top-level IPAM; generated application-owned networks add drivers,
  options, `internal`/IPv6 booleans, and labels.
- Adds generated application-owned volume drivers, options, and labels, plus diagnostics for
  conflicting authored external-volume configuration.
- Remains source-compatible within the 0.1.x policy and supports Rust 1.85.0+; provider and
  runtime behavior remain outside this release's evidence boundary.
