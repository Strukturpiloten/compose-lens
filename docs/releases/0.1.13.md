# ComposeLens 0.1.13

ComposeLens 0.1.13 completes the generated-document half of the service `env_file` boundary added
for authored and merged projects in 0.1.12.

## Added

- `GeneratedEnvironmentFile::short` for ordered scalar path entries.
- `GeneratedEnvironmentFile::long` for mapping entries with independently selected `required` and
  `format: raw` options.
- `GeneratedService::add_environment_file` for insertion-order-preserving construction.
- Sensitive path propagation through the service, builder, and final generated document.
- Exact byte tests plus native `ComposeDocument` parse-back assertions for both syntax forms.

## Semantics

Generation is pure: it neither resolves paths nor opens or parses environment files. The caller
chooses short or long syntax explicitly, and the renderer emits only the supplied long-form
options. Every successful document is parsed through ComposeLens's syntax and native model before
it is returned.

The additions are source-compatible within the documented 0.1.x policy. Rust 1.85.0 remains the
minimum supported version.
