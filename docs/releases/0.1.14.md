# ComposeLens 0.1.14

- Adds loss-aware authored, merged, and generated support for `entrypoint`, `init`, `stop_signal`,
  `stop_grace_period`, `pull_policy`, and `hostname`.
- Adds the same lifecycle for `pids_limit`, `shm_size`, `mem_limit`, `tmpfs`, `sysctls`, `ulimits`,
  `cap_add`, `cap_drop`, and mixed short/long `devices`.
- Keeps syntax variants, provenance, diagnostics, and field-specific merge behavior available
  without inspecting or enforcing host/runtime state.
- Remains source-compatible within the 0.1.x policy and supports Rust 1.85.0+.
