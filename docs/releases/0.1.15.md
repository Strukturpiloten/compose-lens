# ComposeLens 0.1.15

- Adds loss-aware authored, merged, and generated support for service `dns`, `dns_opt`,
  `dns_search`, `expose`, and `annotations`.
- Adds raw `security_opt` support with diagnostic candidates for AppArmor, seccomp,
  no-new-privileges, SELinux labels, Mask, and Unmask. Ambiguous values remain raw; no candidate is
  selected silently.
- Preserves syntax, ordering, duplicates, provenance, reset/override state, and interpolation
  sensitivity according to each field's Compose merge rules.
- Remains source-compatible within the 0.1.x policy and supports Rust 1.85.0+. Runtime behavior and
  cross-format mapping remain outside ComposeLens.
